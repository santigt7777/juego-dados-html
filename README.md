# Suerte en los Dados 🎲

## Descripción
Un videojuego sencillo de azar en el que el usuario lanza dos dados virtuales y busca obtener resultados dobles para ganar. Desarrollado como parte de una actividad de aprendizaje para el despliegue de sitios estáticos.

## Tema seleccionado
Videojuego sencillo de azar.

## Herramientas utilizadas
* **HTML5:** Estructura del contenido.
* **CSS3:** Diseño visual y estilos personalizados.
* **JavaScript:** Lógica del juego (generación de números aleatorios y validación de resultados).
* **GitHub:** Alojamiento del repositorio y control de versiones.
* **Render:** Despliegue del sitio estático.
* **Claude A.I.:** Generador de codigo.

## Funcionalidad principal
Al hacer clic en el botón de lanzamiento, el sistema genera dos números aleatorios (del 1 al 6), muestra los resultados en la interfaz y calcula la suma. Si los números de los dados coinciden (dobles), el jugador recibe un mensaje de victoria.
